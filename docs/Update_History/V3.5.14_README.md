# BV-Note v3.5.14 AI Chat 擴充

## 新增
- 模型選單：GPT-4.1 mini / GPT-4.1 / GPT-5 / GPT-6（需 API 帳戶支援）。
- API 模式：網站 API（由伺服器指定模型）或個人 API Key（BYOK）。
- 附件：PNG/JPEG/WEBP/GIF、TXT/MD/JSON/CSV、PDF（PDF 僅 BYOK）。
- 單檔 5MB，每次最多 5 個；BYOK Worker 請求上限約 12MB（base64 會膨脹）。

## 部署
1. 將網站前端檔案部署到 GitHub Pages。
2. 部署 ai-byok-worker；設定 ALLOWED_ORIGINS 為正式網站 Origin。
3. 部署 cloud-worker，包含 redirect 修正。
4. 在 AI 設定中切換「自己的 OpenAI API Key」，填入 Key 與 BYOK Worker 完整 HTTPS URL（結尾 /ai/responses）。
5. 測試文字、圖片、PDF、模型權限與 CORS。

## 限制與安全
- 網站 API 模式目前仍由 cloud-worker/auth.js 的 OPENAI_MODEL 決定模型；前端選單只對 BYOK 模式生效。
- 附件內容只在本次請求中傳送；本地 Q Block 儲存附件檔名而非附件位元組，重新發送需重新附加。
- 個人 API Key 只保存在當前頁面的輸入欄位，不會寫入 localStorage 或聊天紀錄；會傳送到自行設定的 BYOK Worker，請確認該 Worker 可信。
- 請求大小、上游帳戶模型權限及模型對附件的支援會影響是否成功。
- 既有網站 API 的圖片請求可能受到 cloud-worker 大小限制；PDF 必須走 BYOK。
- 已修改 Worker 的 redirect: error 為 manual，以符合 Cloudflare Workers 限制。
- 尚未進行端到端線上測試。
