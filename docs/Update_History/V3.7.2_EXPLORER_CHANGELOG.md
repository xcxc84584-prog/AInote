# BV-Note v3.7.2｜Explorer 本地選取與搜尋

## 變更
- 保留既有「選取本地 Fold」功能：選擇資料夾後載入 Explorer 樹。
- 保留既有「選取本地文件」功能：可匯入單一 MD/Markdown/TXT 文件成草稿 Root。
- 新增 Explorer 即時搜尋：不區分大小寫，依文件或資料夾名稱篩選。
- 搜尋結果保留所有上層 Fold，並自動展開顯示路徑；其他節點僅暫時隱藏。
- 顯示符合項目數量，提供清除搜尋按鈕。
- 不更動既有 Save、Close、+Fold、+File、Operate、AI Explorer、Cloud 功能。

## 使用方式
1. 點選「選取本地 Fold」開啟本地資料夾，或「選取本地文件」載入單檔。
2. 在搜尋框輸入部分名稱，即可篩選並找到文件。
3. 點擊結果即可開啟文件；清空搜尋可恢復原樹狀目錄。

## 限制
- 本地 Fold 的選取需要瀏覽器支援 File System Access API，通常是桌面版 Chromium + HTTPS。
- 單檔草稿模式目前只支援 MD/Markdown/TXT；PDF 需透過資料夾 Root 使用原有瀏覽方式。
- 搜尋僅比對檔名及資料夾名稱，不搜尋文件內文。
