# BV-Note v3.6.1 — Google Client ID 修復

## 修正
- `cloud-config.js` 的 `BV_GOOGLE_CLIENT_ID` 由空字串改為 Google OAuth Web Client ID。
- `index.html` 使用 `cloud-config.js?v=3.6.1` 避免舊快取。
- 保留原有 Google 登入、Neon 遷移、Worker、AI Chat 搜尋欄清空等功能。

## 部署
將此 ZIP 的網站檔案覆蓋本地 GitHub Pages 專案；在專案根目錄執行：

```powershell
git add .
git commit -m "BV-Note v3.6.1 Fix Google Client ID"
git push origin main
```

GitHub Pages 部署後強制重新整理，在瀏覽器 Console 執行 `window.BV_GOOGLE_CLIENT_ID`，應得到非空的 `...apps.googleusercontent.com`。

## 注意
- Client ID 是公開識別碼；不要把 OAuth Client Secret、Neon 密碼或 API Key 放入前端。
- 這次是前端修復，若 Worker 已部署 v3.6 且 `GOOGLE_CLIENT_ID` Secret 已設定，不需要再次部署 Worker。
- 若仍有 404，請在 DevTools Network 查看該請求的 Request URL；404 未必是 cloud-config.js。
- 已做靜態語法及 ZIP 完整性檢查；Google 登入仍需在實際網站測試。
