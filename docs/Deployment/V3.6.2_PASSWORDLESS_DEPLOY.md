# BV-Note v3.6.2 Google 免密碼登入

## 更新
- 登入視窗優先顯示 Google 登入按鈕；不必輸入 Gmail 或密碼。
- 傳統 Gmail／密碼與邀請碼註冊收合至次要選項，仍可使用。
- Google 身分憑證由 Worker 以 Google JWKS 驗證，建立 BV-Note Session 後自動關閉視窗。
- 新 Google 使用者自動建立帳號；已驗證 Gmail 對應舊帳號時連結原帳號。
- 修正 Google SDK 延遲載入時按鈕不出現；登入後再確認 /api/auth/me 成功。
- Google-only 帳號使用密碼登入時提示改用 Google。

## 部署
1. 解壓縮覆蓋網站目錄（注意保留自己的其他未提交變更）。
2. 確認 Neon 已執行 cloud-worker/migrate_v3_6_google.sql；不要重複刪除或重建表格。
3. 確認 Worker Secrets: DATABASE_URL、GOOGLE_CLIENT_ID；Google OAuth 授權來源為 https://xcxc84584-prog.github.io。
4. 於 cloud-worker 執行 npm install、npx wrangler deploy。
5. 於網站根目錄 git add . && git commit -m "BV-Note v3.6.2 Passwordless Google Login" && git push origin main。
6. 重新整理 GitHub Pages，測試 Google 選擇帳號 → 免密碼登入 → /api/auth/me、登出與重新登入。

## 安全限制
- Google 登入不是 Gmail 郵件驗證碼；無需 Resend。
- 舊帳號以 Google 驗證的 Gmail 地址自動連結。對非 Gmail、既有其他登入提供者或有帳號所有權爭議的情況，應另做人工/額外驗證，避免誤合併。
- Session 目前仍存於 localStorage；正式公開使用建議升級 HttpOnly Secure SameSite Cookie。
- 未在實際 Google / Neon / Cloudflare 環境做端到端測試。
