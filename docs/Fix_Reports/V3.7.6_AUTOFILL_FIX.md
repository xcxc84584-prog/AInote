# BV-Note v3.7.6 — Chrome Autofill 修正

- 對 Explorer、AI Chat 搜尋、雲端 Hash 搜尋、AI Markdown 輸入框設定獨立 `name` 和 `autocomplete=off`。
- 非登入輸入框初始 `readonly`，使用者點擊、聚焦或鍵盤輸入時解除，以降低 Chrome 自動填入機率。
- Explorer 動態命名欄位加上明確語意。
- 登入 Email / 密碼使用標準 `username` / `current-password` 語意，避免一般欄位被誤判。
- 未清除任何 localStorage、IndexedDB 或使用者文件。

注意：Chrome 擴充套件與第三方密碼管理器可能忽略網頁設定，無法保證百分之百阻止填入。

驗證：JavaScript 語法檢查與 ZIP 完整性檢查；未進行瀏覽器端測試。
