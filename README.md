## v2.2.6 新文件流程
「新文件」會先選取本地父資料夾，再建立 Root 資料夾「新檔案」及子文件「新文件.md」，寫入磁碟並載入 Explorer。若名稱已存在，使用「新檔案 (2)」等名稱避免覆寫。需要支援 File System Access API 的瀏覽器（HTTPS 或 localhost）；取消選擇不會改變現有文件。
