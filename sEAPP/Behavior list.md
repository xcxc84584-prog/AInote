# Behavior list

| Behavior ID | Condition | Action |
|---|---|---|
| B1 | 使用者輸入 Markdown | 更新文件並標示未儲存 |
| B2 | 使用者開啟 Root | 載入樹及節點資料 |
| B3 | 使用者選擇文件 | 讀取內容並渲染 |
| B4 | 使用者 Commit | 寫入原始文件 |
| B5 | 使用者新增或管理節點 | 修改 Explorer 樹 |
| B6 | 使用者建立目錄 | 保存並呈現目錄 |
| B7 | 使用者插入或刪除文本 | 修改選定區段 |
| B8 | 使用者插入圖片 | 將圖片嵌入 Markdown |
| B9 | 使用者匯入文件 | 複製到指定資料夾 |
| B10 | 使用者匯出節點 | 下載 ZIP |
| B11 | 文件包含 Mermaid 區塊 | 合法圖形化顯示；語法錯誤時保留原碼 |
| B12 | 使用者切換編輯／瀏覽 | 切換模式並保留狀態 |
| B13 | 使用者重新整理頁面 | 恢復同分頁工作階段 |
