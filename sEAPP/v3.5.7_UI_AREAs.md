# BV-Note v3.5.7｜sEAPP UI-only AREA 整合

| AREA | 責任 | 來源與策略 | 本版狀態 |
|---|---|---|---|
| A17 UI / PageSwitch | 一般模式與 AI Chat Page 切換 | `ai-chat-ui.js` 呼叫現有 `BVShowPage`；不複製一般編輯器 | UI 可切換 |
| A37 ChatRegistry | Chat → Q/A Block 樹狀 Explorer | `ai-chat-ui.js` 暫存於記憶體，後續對接原 IndexedDB | UI 示意 |
| A1 MarkdownSource | Q/A 原始 Markdown | 未變更 `renderer.js` | 未串接 |
| A2/A3 Markdown/MathRenderer | 統一渲染 | 後續重用 `renderer.js`；禁止複製解析器 | 未串接 |
| TOC / Annotation | 目錄化、標註、標記列表 | 右上「目錄」為統一入口；後續抽離 `toc.js` 與 AI Blocks 共用 | UI 入口 |
| ChatInput / AIRequest | BYOK API Key 與 AI 請求 | 只有 Model、Key、Send 外觀；不得傳送請求或保存 Key | UI 佔位 |
| Save / Download | 工作副本保存與 Markdown 匯出 | 右上保留 SAVE / DOWNLOAD；不執行 | UI 佔位 |

## BEHAVIOR
B1 一般模式 → AI → BACK → 一般模式，保留一般編輯器 DOM。
B2 NEW CHAT 建立暫存示意聊天，Explorer 可展開 Q/A 節點。
B3 點擊 QA 節點定位中央 Block；無真實資料讀取。
B4 右上目錄包含目錄化、標註、標記列表；尚未套用資料操作。
B5 SEND、SAVE、DOWNLOAD、API Key 設定不呼叫網路、不寫入資料。

## STEP / 驗收
S1 開啟 AI、收合／展開 Explorer、BACK。
S2 NEW CHAT，搜尋標題，展開 Chat → QA Block。
S3 點選 QA Block 捲動定位。
S4 打開右上「目錄」選單，確認三個共用功能入口。
S5 點選 SAVE / DOWNLOAD / Send，應只顯示未啟用提示。
