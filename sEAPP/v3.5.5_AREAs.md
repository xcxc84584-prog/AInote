# v3.5.5 sEAPP AREA 擴充

沿用 A1 MarkdownSource、A2 MarkdownRenderer、A3 MathRenderer、A7 EditorMode、A17 UIState，不另寫渲染器。

| AREA | 輸入 | 輸出 | 檔案 |
|---|---|---|---|
| A35 ShareLinkInput | 使用者提供的 ChatGPT 分享連結 | 經 HTTPS/網域驗證的 URL | ai-chat-ui.js |
| A36 ShareContent | 分享頁面可讀內容或使用者貼上文字 | Q/A Block 工作副本（未驗證完整性） | ai-chat-ui.js |
| A37 LocalChatRegistry | Chat metadata + blocks | IndexedDB 本地紀錄、Explorer 表格 | ai-chat-ui.js |

**流程：** A35 → A36 → A37 → A7；A36 → A1 → A2/A3（既有 renderer）。

**限制：** CORS 阻擋時要求使用者貼上內容；不得以瀏覽器端 CORS 失敗聲稱已匯入聊天。純文字角色推斷屬啟發式，可能不準確。
