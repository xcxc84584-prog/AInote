# BV-Note v3.7.3 — Multi-Root Explorer

- Explorer can keep multiple local Root folders in one workspace.
- `Open` adds another Root instead of replacing the existing one.
- All opened Root trees are visible; clicking a file switches the active Root to its owner.
- Existing create, save, import, export, cloud operations run against the active Root.
- `Close` removes only the active Root from the Explorer workspace and activates another opened Root.
- File edit buffers are retained in memory on Root switching; use Save to persist changes to disk.
- Browser file-system permissions may need to be granted again after a reload. Multi-Root handles are not persisted across reloads.
